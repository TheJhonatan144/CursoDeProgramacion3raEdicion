# Bootcamp Programacion de Cero a POO 3ra Edicion

## Descripcion
Este repositorio corresponde al bootcamp **Programacion de Cero a POO**, un curso virtual en vivo orientado a estudaintes que estan iniciando en programacion y desean construir una base solida antes de avanzar hacia Programacion Orientada a Objetos.

El enfoque del bootcamp sigue una progresion academica practica:
**Logica de programacion - diagramas - pseudocodigo - C++ estructurado - Java POO**

A lo largo del curso, sed trabaja con clases en vivo, ejercicios practicos, tareas autonomas, evaluaciones y proyectos, manteniendo siempre una metodologia centrada en comprender primero la logica, luego representarla y finalmente implementar en codigo.

## Objetivo del repositorio
Este repositorio tiene como finalidad organizar y almacenar el materia, ejercicios, practicas y proyectos desarrollados durante el bootcamp, ademas de servir como evidencia del proceso de aprendizaje mediante el uso de Git y GitHub.

## Contenido del curso
Hasta este punto del bootcamp, se ha trabajo temas como:

- logica y resolucion de problemas
- diagramas de flujo 
- pseudocodigo en PSeint
- introduccion a C++
- variables, operadores y entrada/salida
- estructuras condicionales
- estructuras repetitivas
- arreglos 
- funciones y modularizacion 
- introduccion a Git y GitHub

## Metdologia de trabajo 
Duramnte el bootcamp se promueve un flujo de trabajo ordenado. Esto incluye 
- desarrolar ejercicios y proyectos de forma progresiva
- registrar avances mediante commits
- publicar cambios en GitHub
- mantener estructura clasra en los repositorio 
- documentar de forma basica los proyectos mediante README
